# 🚀 Akshansh Vaishnav — Developer Portfolio

Welcome to my interactive, full-stack developer portfolio built with **React**, **CSS**, **Three.js**. This website showcases my work, skills, and provides a direct way to connect with me through a contact form powered by **EmailJS**.

## 🌐 Live Demo

👉 [Visit Portfolio](https://akshansh.vercel.app)

---

## 🧩 Features

- ✨ **Attractive Hero Section**  
- 💼 **Project carousel with video + logo previews**
- 👨‍💻 **Detailed "About Me" section with skills and hobbies**
- 📄 **Downloadable Resume**
- 📬 **Fully functional contact form** (EmailJS integration)
- 🎨 **Modern, responsive design** using vanilla CSS and gradients
- 🌙 **Dark theme** for elegant visual consistency
